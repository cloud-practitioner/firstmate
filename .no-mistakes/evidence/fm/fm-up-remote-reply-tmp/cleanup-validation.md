The six targeted CLI scenarios passed in two consecutive final runs. No project source or test files were changed. All disposable homes, private temporary directories, local transport configuration, fixture checkout, and loopback endpoint were removed; no test processes remained.

| Scenario | Observable behavior |

## Method

`live-cleanup-driver.py` invokes the unchanged executable interfaces in the target worktree. Protocol envelopes are generated by the real `fm-remote-delta-read.sh`; only the adversarial corruption tests alter input data. Captures/acknowledgements use the real process-event runner. Each home is marked with `bin/fm-lab-home.sh create`. TMPDIR deliberately contains spaces.

Interruption tests use `/usr/bin/ssh` with private `-F` configuration and a disposable loopback TCP endpoint that sends a protocol banner, then stalls the SSH handshake. No product executable, SSH client, login, or returned reply is mocked. No operator data, credentials, default fleet, or shared server is used. SIGTERM is delivered to each isolated process group; the driver allows child cleanup to settle before inspecting the filesystem.
